# 🏥 Sistema de Gerenciamento de Clínica Médica

## 📖 Visão Geral
Este repositório contém a modelagem e os scripts de banco de dados desenvolvidos para o sistema de uma clínica médica. O projeto tem como objetivo central estruturar os dados para suportar as operações de agendamento e atendimento, aplicando boas práticas de modelagem relacional.

Todo o diagrama Entidade-Relacionamento foi construído utilizando o **MySQL Workbench**, e os arquivos estão organizados para facilitar o versionamento e o trabalho em equipe, separando o modelo visual dos scripts de execução estruturados para o backend.

## 🎯 Tema
**Banco de Dados para Clínica Médica**

O modelo de dados foi projetado para gerenciar os fluxos fundamentais do dia a dia de uma clínica. As principais regras de negócio mapeadas incluem:
*   **Pacientes:** Cadastro de dados pessoais, informações de contato e endereço.
*   **Médicos / Especialidades:** Registro dos profissionais de saúde, seus respectivos registros médicos (CRM) e áreas de atuação.
*   **Agendamentos de Consultas:** Controle de marcação relacionando pacientes aos médicos, incluindo datas, horários e o status do atendimento (pendente, realizado, cancelado).
*   **Prontuários:** Registros do histórico clínico e observações médicas atreladas a cada consulta realizada.
